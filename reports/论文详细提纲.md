## 摘要（1 页，约 600 字）

**必须包含四要素**，缺一个就扣分：

1. **问题**：多源零散信号 → 结构化可量化决策（一句话）
2. **方法**：多源采集 + 三层去重 + 规则与大模型协同判别 + 分层聚类 + 熵权-AHP 组合赋权
3. **数字**（一个都不能少）：
   - 采集 917 条，去重后 **735 条**入表，识别机会 **52 条**（7.1%）
   - 主题簇 **13 个**，阈值 **τ=0.36**，判别 **F1=0.95**（标注集）
   - 聚类稳定性 **ARI 0.77/0.75**，敏感性 **Spearman 0.996**
4. **结论**：机会密度由来源形态决定（问答社区 54.3% vs 资讯类 0%）

**关键词**：AI 应用机会；多源数据采集；机会判别；文本聚类；熵权法；组合赋权

## 三、机会判别模型（6 页，约 3000 字）—— 全文最重的一章

### 3.1 判定规则的量化（1.5 页）
**表 4-1**：赛题四条规则 → 可计算特征

| 规则 | 特征化 | 信号词示例 |
|---|---|---|
| 真实需求 | 需求句式正则 + 语义打分 | "有没有…""求推荐""太麻烦" |
| AI 为核心 | 能力词表 + 语义打分 | 识别/生成/理解/预测 |
| 可落地 | 排除项检测 | "自研模型""海量标注" |
| 排除情形 | 六类黑名单分类 | 资讯/广告/教程/招聘/政策/吐槽 |

### 3.2 判别打分（1.5 页）
公式（必须写出来）：

```
s = w₁·has_need + w₂·ai_core + w₃·feasible
conf = σ(slope · s + bias) × (1 − exclude_penalty)
```

参数：w = (0.40, 0.35, 0.25)，slope=3.5，bias=−1.925

> 说明：slope/bias 的作用是把加权和拉伸到有判别力的区间，不是拍脑袋——要写"标定过程"

### 3.3 阈值标定（1.5 页，**核心得分点**）
