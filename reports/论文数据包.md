| 级别 | 条件 | 行为 | 效果 |
|---|---|---|---|

| 二级 | 无 Key，但命中预置缓存 | 直接返回缓存结果 | **零配置复现论文结果** |
| 三级 | 无 Key 且未命中 | 抛出异常，上层回退规则判别 | 仍能产出四件套，质量降一档 |

**公网访客如何发起需求**：系统为其开放「**离线采集**」——采集与分析只读本地缓存、判别退回规则模型，**不发起任何外部 API 调用**，因此不消耗系统管理员额度、也不需要访客提供 Key。代价是缓存未命中时判别质量略低于在线模式。

配套限制：每源最多 40 条、同一时刻只允许一个采集任务（文件锁）、可在 `config.yaml` 用 `ui.allow_public_collect` 一键关闭。

**访客自带 Key（可选）**：访客也可在侧栏填入自己的模型 Key 走在线模式。该 Key 仅存于会话内存，**不写入 .env、不落盘、不进日志**，通过子进程环境变量传递，采集结束后随会话销毁。这条路径既保证质量，又不动系统管理员的额度。
