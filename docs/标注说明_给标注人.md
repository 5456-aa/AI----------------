# 标注说明（给标注人）

> 你要做的事：**给 40 条记录打标签**，判断它是否构成「AI 应用机会」。
> 全程约 15~20 分钟。不用注册、不用装软件，用 Excel 打开填一列就行。

---

## 一、怎么开始（两种方式，任选）

### 方式 A：在线标（推荐，会自动存）

1. 浏览器打开队长给的地址，形如 **`http://10.162.58.253:8504`**
   （必须和队长在同一个 WiFi / 局域网）
2. 顶部填你的名字（拼音即可，用来分开保存）
3. 一条一条点「✅ 是机会」或「❌ 非机会」，点完自动跳下一条

每点一次自动保存到 `data/label/by_person/<你的名字>.csv`，**关掉页面也不丢**。
不需要点保存按钮，也不需要发文件给队长。

### 方式 B：离线用 Excel 标

1. 拿到文件：**`双标样本_B.xlsx`**（或 `双标样本_C.xlsx`，看你被分到哪个）
2. 用 Excel 打开，切到 **「标注」** 工作表
3. **只在 `label` 列（F 列，浅黄色）填 1 或 0**，其他列不要动

填完 **Ctrl+S 保存**，把文件发回给队长。

> 两种方式题目完全一样（同一批 40 条）。表里没有别人的答案，请**独立判断**，不要去问、不要对照。

## 二、判定标准（四条同时满足才算「机会」）

| # | 条件 | 说明 |
|---|---|---|
| ① | **有真实需求** | 具体的人在表达具体困难 / 求助 / 期望。纯陈述事实、转述观点不算 |
| ② | **AI 是核心** | 这个问题必须靠 AI 能力（语义理解、生成、识别、预测）才能解决；普通信息化、加人力就能解决的，不算 |
| ③ | **技术可落地** | 现有技术能做，不需要自研基础模型、不需要海量标注数据、不需要专用硬件 |
| ④ | **排除情形** | 纯资讯、广告、教程、招聘、政策公告、无诉求的吐槽 → 一律 **0** |

### 一句话口诀

> **作者在“分享/说明/记录” → 0；用户在“抱怨/求助/想要” → 1**

## 三、真实例子（来自本次数据，照着这个感觉判）

### ✅ 判 1 的典型

```
标题：Python 获取 Google 音频时频繁出现验证码，有什么可靠的解决方案吗
正文：Python 获取 Google 音频时频繁出现验证码，有什么可靠的解决方案吗
      Python 获取 Google 音频时频繁出现验证码…
```
**为什么是 1**：有人在问“有没有可靠方案”，是具体问题 + 具体困难，AI/自动化能解决。

```
标题：小程序报错问题：页面崩溃了，如何解决
正文：自学学习怎么写小程序，教学案例页面之后发现控件…控制台报错…
```
**为什么是 1**：真实的人遇到真实问题，在求解决方案。

### ❌ 判 0 的典型

```
标题：AI 实践：智能客服系统的技术架构与应用
正文：在当今移动端畅行的今天，智能客服系统正逐渐成为企业服务体验的核心…
```
**为什么是 0**：这是**技术文章**，作者在讲解架构，没有任何人在描述自己的困难。

```
标题：Datadog 推出面向 SRE 的故障排查专用 AI 模型
正文：点击查看原文 >
```
**为什么是 0**：**产品资讯**，厂商发布消息，不是用户需求。

## 四、最容易判错的三种情况

| 情况 | 怎么判 |
|---|---|
| 标题有“AI”“智能”字样 | ❌ 不代表是机会。看有没有**具体的人在求助** |
| 技术教程里提到“痛点” | ❌ 作者在讲原理，不是自己有需求 → 0 |
| 问题跟技术有关但**跟 AI 无关**（如证书报错、接口超时） | ❌ AI 不是核心 → 0 |
| 拿不准 | 按最接近的一条判，**不要留空** |

## 五、常见疑问

**Q：有些记录正文很短，看不出来怎么办？**
A：按标题判。标题能看出是“文章/教程/资讯”就 0，能看出“有人求助”就 1。

**Q：我判的和第一个人不一样怎么办？**
A：正常，这就是为什么要做这个检验。**按你的判断填**，不要猜别人怎么想。

**Q：一条记录里既有教程又有求助呢？**
A：看主体。整篇以讲解为主 → 0；主体是“我遇到问题，怎么解决” → 1。

**Q：要不要写备注？**
A：拿不准时写一句理由，方便后面复盘。**备注不影响评分**。

## 六、交回之后会发生什么

1. 你的 40 条和第一个人的 120 条取交集
2. 计算 **Cohen's κ**（两个人判断的一致程度）
3. κ ≥ 0.6 → 说明标准清晰、标注可信，写进论文作为「模型评价客观性」的证据
4. κ < 0.4 → 我们三人一起复盘分歧条目，统一口径后重标

**这个检验的目的不是挑错，是证明标注标准经得起检验。**
