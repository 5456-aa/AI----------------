# 公网演示方案（评委不在局域网时怎么办）

> 结论先说：**提交的离线包才是评分依据**，公网地址只是"能点开看看"的加分项。
> 本项目已内置一条命令开公网：双击 `开启公网访问.bat`。

---

## 一、三种方案对比

| 方案 | 成本 | 地址稳定性 | 需要 | 适合 |
|---|---|---|---|---|
| **A. Cloudflare 临时隧道**（已内置） | 免费 | 每次重启变 | 联网、电脑开着 | **演示、答辩现场** |
| B. Cloudflare 固定隧道 | 免费 | 固定 | Cloudflare 账号 + 一个域名 | 长期展示 |
| C. 云服务器部署 | 几十元/月 | 固定 | 服务器 + 备案（国内） | 长期对外 |
| D. Streamlit Community Cloud | 免费 | 固定 | GitHub 仓库（需公开/授权） | 长期展示 |

---

## 二、方案 A：已内置，双击即用

### 操作

1. 双击 **`启动系统.bat`**（本机三服务：8500 / 8501 / 8505）
2. 双击 **`开启公网访问.bat`**
3. 窗口里会打印两行地址：

```
https://xxxx-yyyy.trycloudflare.com   ← 只有一个地址，进入后左侧切换三个页面
```

4. 把这一个地址发给评委即可（手机 4G 也能打开），
   进入后左侧菜单在「首页 / 分析看板 / 问答咨询」之间切换

### 实测记录（2026-11-15）

```
✅ 8500 → https://advantage-...trycloudflare.com   /_stcore/health 200 ok
✅ 8501 → https://duo-...trycloudflare.com         /_stcore/health 200 ok
```

### 自动做的安全处理

**按访问来源自动判定权限**（不需要手动设环境变量）：

| 访问来源 | 判定 | 能力 |
|---|---|---|
| `localhost` / `127.0.0.1` | 本机 | 完整权限，侧栏出现「🔓 管理模式」开关 |
| `192.168.*` / `10.*` / `172.16~31.*` | 局域网 | 完整权限 |
| 其它域名（隧道 / 云主机） | 公网 | **强制只读**，开关与设置面板均不可见 |

### 公网下的页面跳转

两个页面跑在不同端口，公网是**两个不同域名**，所以链接不能写死：

- 隧道启动时把地址写入 `data/runtime/public_urls.json`；
- 首页按访问来源选择链接：本机 → `localhost:8501`；公网 → 对应的公网看板地址；
- 看板顶部给公网访客一个「← 返回首页」。

| 风险 | 处理 |
|---|---|
| 访客改写本机 API Key | 公网请求自动降为决策者，分析看板**隐藏模型设置面板** |
| 访客滥用采集 | 公网只允许**离线采集**（不调 API），每源 ≤40 条，单任务锁 |
| 访客想用在线模式 | 侧栏可填**他自己的 Key**：只存会话内存，不落盘、不进日志 |
| 暴露标注/写数据页面 | 只映射 8500 / 8501，**标注工具不外露** |
| 地址泄漏后长期可访问 | 关闭窗口即断开，地址立即失效 |

## 三、必须知道的三个限制

1. **地址每次重启都会变** —— 重启后要重新发一次
2. **本机关机/断网就失效** —— 评委访问期间电脑必须开着
3. **访问速度受网络影响** —— Cloudflare 在国内时快时慢，评委打不开时请以提交包为准

> 所以：**不要把公网地址当成唯一入口**。提交包里已经有完整的四份 CSV、
> 11 张截图、单文件 HTML 报告，评委不联网也能看到全部结论。

## 四、如果要求"长期稳定可访问"

### 方案 B：Cloudflare 固定隧道（推荐，免费）

1. 注册 Cloudflare，添加一个域名
2. `cloudflared tunnel login`
3. `cloudflared tunnel create ai-opp`
4. 配置 `config.yml` 绑定域名 → `cloudflared tunnel route dns ai-opp demo.你的域名.com`
5. `cloudflared tunnel run ai-opp`

地址固定为 `https://demo.你的域名.com`，不再变化。

### 方案 D：Streamlit Community Cloud（最省事）

1. 把项目推到 GitHub（**先确认 `.env` 没有被提交**，本项目有 `guard_secrets.py` 可自检）
2. 在 share.streamlit.io 新建 app，入口填 `ui/home.py`
3. 在 Secrets 里填 `DEEPSEEK_API_KEY`（可选，不填则走离线缓存）

优点：有公网地址、不依赖你电脑开机。
注意：免费实例会休眠，首次打开要等几十秒。
