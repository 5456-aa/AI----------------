# 怎么配 API Key（手把手，不需要懂编程）

> 一句话：**Key 就是一把钥匙，程序拿它去调用大模型服务**，按调用量计费。
> 你们要做的事只有两件：**去官网领一把钥匙**，**把钥匙贴进项目里**。

---

## 0. 先确认：不配 Key 也能跑

不配 Key，程序照样能跑完、照样出四个 CSV —— 只是判别和起名用的是"关键词规则"，
质量比大模型差一截。**所以配 Key 是加分项，不是卡点**，不用怕配错把项目搞坏。

---

## 1. 第一步：去 DeepSeek 官网领 Key

1. 浏览器打开 **https://platform.deepseek.com**
2. 右上角「登录 / 注册」，用手机号注册（要收短信验证码）
3. 登录后，看**左侧竖排菜单**，找到 **「API keys」**（中文界面可能叫「API 密钥」）
   - 找不到就用这个直达链接：https://platform.deepseek.com/api_keys
4. 点 **「创建 API key」** / 「Create new API key」
   - 名字随便填，比如 `competition`
   - 点确定后，页面会显示一串 `sk-` 开头的一串字符
5. **立刻复制**（重要：这串只显示这一次，关掉就再也看不到，只能重新创建）

> **充值**：DeepSeek 需要账户有余额才能调用。左侧「充值」，充 **10 元**就够这次比赛用
> （deepseek-chat 大约 1 元 / 百万字，我们全部数据跑一遍也就几分钱）。

**领 Key 时会看到的界面大致是这样：**

```
┌─────────────────────────────────────────┐
│  DeepSeek 开放平台                        │
│  ┌──────────┐                            │
│  │ 用量信息  │   ← 这里能看到余额           │
│  │ API keys │   ← 点这里                   │
│  │ 充值     │                            │
│  └──────────┘                            │
│                                          │
│   API keys            [+ 创建 API key]    │
│   sk-3f8a...c21d     created 2026-11-11  │
└─────────────────────────────────────────┘
```

---

## 2. 第二步：把 Key 贴进项目（双击一个文件就完事）

1. 打开文件夹 **项目文件夹**（本项目根目录）
2. 找到一个叫 **`设置KEY.bat`** 的文件（图标是齿轮/窗口，名字就是这四个字）
3. **双击它**
4. 会弹出一个黑色窗口，上面写着「第一步：配置大模型 API Key」
5. 光标停在「把 key 粘贴到这里，按回车：」后面
6. **右键粘贴**（或 Ctrl+V）刚才复制的 `sk-...`
7. **按回车**
8. 等 3~10 秒，它会自动测试这个 Key 好不好使

**这个 bat 帮你做了三件事**（你不需要手动做）：
- 把 key 写进 项目根目录下的 `.env` 这个文件
- 调一次真实接口验证 key 有效
- 告诉你成功还是失败

> 为什么用 `.env` 文件而不是让你敲命令？因为 `.env` 不会被提交到 git（`.gitignore` 已经排除），
> 也不会出现在截图里，最不容易出安全事故。

---

## 3. 第三步：看结果（成功长这样）

```
配置：base_url = https://api.deepseek.com/v1
      model    = deepseek-chat
      key      = sk-3…c21d（长度 35）  （来源：.env 文件）
客户端状态：enabled=True，缓存 0 条

[成功] 往返 0.83s，返回：{'ok': True, 'msg': 'pong'}

LLM 可用，可以跑判别/翻译/主题名了：
  python run_all.py --track all --batch B20261111-01 --force
```

看到 **`[成功]`** 就成了，关掉窗口。

接着双击 **`跑全流程.bat`**，它会先用大模型跑一遍全流程（约 3~10 分钟，
因为要逐条调用接口），跑完在 `data\out\` 里就是四个 CSV。

## 4. 失败怎么办（对照表）

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| `HTTP 401 ... api key is invalid` | key 抄错了 / 已被删除 | 回官网重新创建一把，重新双击「设置KEY.bat」 |
| `HTTP 402 ... Insufficient Balance` | 余额不足 | 去「充值」充 10 元 |
| `HTTP 404` | base_url 写错 | 检查 `config.yaml` 里 `llm.base_url` 必须是 `https://api.deepseek.com/v1`（**带 /v1**） |
| `ConnectTimeout` / `Max retries exceeded` | 网络不通 | 换个网络（手机热点）再试；或公司/学校网限制 |
| `[提醒] 这个 key 不是以 sk- 开头` | 复制时少粘了前缀 | 重新复制完整的一串 |
| 粘贴后窗口闪一下就没 | 可能粘了空内容 | 重新双击，粘贴后确认光标后有字符再回车 |

> 改好之后**不用重装什么**，再双击一次「设置KEY.bat」覆盖旧 key 即可。

---

## 5. 三种配置方式的区别（了解即可，用第一种就行）

| 方式 | 怎么弄 | 什么时候用 |
|---|---|---|
| **`.env` 文件**（推荐） | 双击「设置KEY.bat」 | 日常都用这个；关掉窗口再开也有效 |
| 当前窗口临时变量 | `$env:DEEPSEEK_API_KEY="sk-..."` | 只想试一次，不想留文件 |
| 系统环境变量 | `setx DEEPSEEK_API_KEY "sk-..."` 然后**关窗口重开** | 换电脑/多人共用时最省事，但 setx 对已打开的窗口无效，这是最常见的坑 |

程序读取顺序：**系统环境变量 → `.env` 文件**，谁有值用谁。

---

## 6. 安全提醒（这段很重要）

1. **别把 key 发到群里 / 贴进论文 / 写进代码注释** —— 提交时评委会看源码，泄露算事故。
2. **别把 key 截图**发进 chat 或文档，尤其是 AI 使用报告里。
3. 如果怀疑泄露了，去官网把这把 key **删除**，再建一把新的。
4. `.env` 文件本身**不要提交**（已经写在 `.gitignore` 里，但手动打包 zip 时注意别带上）。

---

## 7. 想换通义千问 / Moonshot / 本地模型？

不用改代码，只改 `config.yaml` 最下面 `llm:` 那三行：

```yaml
llm:
  base_url: "https://dashscope.aliyuncs.com/compatible-mode/v1"   # 通义
  model: "qwen-plus"
  api_key_env: "DASHSCOPE_API_KEY"
```

然后双击「设置KEY.bat」时，它会读这个新的变量名（脚本会自动跟随配置）。
注意：不同家的 `base_url` 都要带 `/v1` 或 `/compatible-mode/v1` 这类后缀，具体看各家文档。

---

## 8. 配好之后会自动保护你（密钥熔断）

从这一步起，每次跑流程前会自动做一次"泄漏自检"：

- 扫项目目录里所有文本文件，看有没有 `sk-` 开头的长串、或者 `api_key = "..."` 这种硬编码；
- **一旦发现，立刻熔断**：写下 `.leak_alert` 标记，流程直接停下，退出码 3，不出结果也不出包；
- 屏幕上会打印是**哪个文件的第几行**、以及三步处理办法。

恢复办法：

```
python scripts/guard_secrets.py --clear
```

**它不会碰的东西**（可以放心）：不读 `.dsh` 里的登录凭据、不改系统环境变量、不动当前对话用的 API 通道。
作用范围只有 项目根目录这个文件夹。
