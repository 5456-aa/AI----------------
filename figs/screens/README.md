## 重新生成

```bash
python run_all.py --track all --batch B20261113-01 --force   # 先跑出最新结果
python scripts/make_html_report.py                            # 生成单文件 HTML
# 然后用浏览器打开 reports/系统可视化报告.html，分段截图
```
